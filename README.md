# Invoice Generator - MERN Stack

A full-stack web application to create, manage, and download invoices as PDF. Built for Ola Krutrim submission.

### 🚀 Live Demo
**Frontend:** https://invoice-frontend-chi-three.vercel.app

**Backend API:** https://invoice-backend-gkvk.onrender.com

### ✨ Features
- **User Authentication:** Secure Register/Login using JWT
- **Invoice Management:** Create, view, edit, and delete invoices
- **Auto Calculations:** Automatic tax and total amount calculation
- **PDF Download:** Export any invoice as a PDF with one click
- **Responsive Design:** Works smoothly on mobile, tablet, and desktop

### 🛠️ Tech Stack
| Area | Technology |
| --- | --- |
| **Frontend** | React.js, Tailwind CSS, Axios |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB Atlas |
| **Auth** | JSON Web Tokens (JWT), bcrypt |
| **Deployment** | Vercel (Frontend), Render (Backend) |
